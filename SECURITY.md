# Security Policy

## Supported Versions

The `main` branch is the supported development and release line.

## Reporting a Vulnerability

Report vulnerabilities privately through GitHub Security Advisories for this repository. Do not open a public issue for exploitable parser, code generation, path handling, memory safety, or build-chain findings.

Include:

- Affected commit or release tag.
- Host OS and compiler toolchain.
- Minimal source file or command that reproduces the issue.
- Expected behavior, observed behavior, and sanitizer output when available.

Maintainers will acknowledge valid reports, reproduce the issue, and release a fix before public disclosure.
